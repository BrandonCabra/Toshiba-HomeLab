# 02. Instalación de Ubuntu Server

## 1. Objetivo

Documentar el proceso de instalación y preparación del sistema operativo
Ubuntu Server en un equipo Toshiba Satellite C655, reutilizado como
servidor doméstico para aprendizaje y experimentación.

## 2. Hardware utilizado

| Componente | Característica |
|---|---|
| Equipo | Toshiba Satellite C655 |
| Procesador | Intel Core i3-2350M |
| Memoria RAM | Aproximadamente 4 GB |
| Almacenamiento | HDD de 320 GB |

## 3. Sistema operativo

- Sistema: Ubuntu Server 26.04.1 LTS
- Arquitectura: AMD64
- Nombre del servidor: toshiba-server
- Usuario administrativo: devadmin

## 4. Preparación inicial

Después de instalar el sistema operativo se realizaron las siguientes
actividades:

- Actualización de los repositorios.
- Actualización de los paquetes instalados.
- Verificación del almacenamiento disponible.
- Configuración de acceso mediante SSH.
- Organización de directorios para proyectos, datos y respaldos.
- Configuración de memoria Swap.

## 5. Acceso remoto

Se habilitó OpenSSH para administrar el servidor desde otros equipos
sin necesidad de conectar directamente un monitor y teclado.

## 6. Resultado

El equipo quedó preparado como servidor Linux para alojar servicios,
administrar archivos, desarrollar proyectos y practicar tecnologías
relacionadas con infraestructura y DevOps.
